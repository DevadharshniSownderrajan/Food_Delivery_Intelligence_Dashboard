# 🍽️ Food Sales Dashboard

## 📌 Project Overview

This project is a simple **Food Sales Dashboard created using Microsoft Excel**. It helps visualize and analyze food sales data through interactive charts, tables, and key performance indicators.

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Excel Dashboard

## 📊 Dashboard Insights

The dashboard provides insights into:

* Total sales
* Total orders
* Food/item performance
* Sales trends
* Category-wise analysis
* Other key sales metrics

## 🎯 Objective

The main objective of this project is to transform raw food sales data into a **simple and interactive dashboard** that makes it easier to understand sales performance and identify useful business insights.



## 🚀 Key Learning

Through this project, I practiced:

* Data cleaning and organization
* Creating Pivot Tables
* Using Pivot Charts
* Adding Slicers for interactivity
* Building an Excel dashboard
* Presenting data in a simple and meaningful way
